# Runtime I/O 2.2.1: Implementation Plan

> **For agentic workers:** Use `superpowers:executing-plans` to implement the
> approved tasks sequentially. Subagents require an explicit choice by the user.
> Track execution with the checkboxes in the linked plans.

**Goal:** Разработать I1/I2/O1/O2 после смерженного F, сохранив default runtime
contracts и добавляя resilience policies только opt-in в рамках **2.2.1**.

**Architecture:** Сначала одинаковый baseline harness, затем extraction processing
supervisor, shared retry admission и measured allocation/window improvements.
Late registry, component ledger и observer dispatcher сохраняют собственные
границы lifetime; executor остаётся orchestration boundary.

**Tech Stack:** .NET 10 / SDK 10.0.401, C#, xUnit v3/Microsoft.Testing.Platform,
FluentAssertions, FakeTimeProvider, bounded Channels, BenchmarkDotNet.

**Spec:** [Runtime I/O design](../specs/2026-10-11-runtime-io-2.2.1-design.ru.md).

- API additions только Unshipped; не переписывать Shipped/immutable baselines.
- VersionPrefix остаётся 2.2.1, previous-stable остаётся 2.2.0; не повышать до 2.3.0.
- Зафиксировать конкретное versioning исключение при реализации; публикация отдельно.
- Не параллелить edits shared runtime/registry/snapshot/StageExecutor файлов.
- Every new behavior: red regression → минимальное изменение → green → review.
- Не утверждать performance improvement без paired raw measurements.

## Review Focus

1. Cancellation после reserve, но до invocation: ни token leak, ни fake callback;
   I2 tests `ReservedRetryCancellation_RefundsWithoutCallback`.
2. Refill при held delayed reservations: actual starts не превышают burst;
   I2 tests `DelayedReservations_DoNotAccumulateRefillBurst`.
3. Borrowed/scope late attempt после finalization timeout: Dispose join
   сохраняется; I1/I2 tests `ExternalLateAttempt_HoldsAdmissionUntilObservation`.
4. Zero observers вместе с telemetry/sink fault: metrics/activity и первичная
   ошибка сохраняются; O1 tests `NoObservers_PreservesTelemetryAndSinkFailure`.
5. Burst на границе sampling window: exact граница и explicit bucket approximation
   проверены отдельно; O2 tests `BoundaryBurst_DivergenceExplainedByOldestBucket`.
